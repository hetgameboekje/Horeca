# Horeca

A website project built for the hospitality (horeca) sector, developed as a team project.

**Made by:** Elise, Sylvester, Kjenno, Timo

## About

This repository contains the source of a horeca (hotel/restaurant/café) website, built with PHP, HTML and CSS. It includes a contact page with a contact form, and separate sections for items (e.g. menu/product listings) and website pages.

Work on this project was split across the team: most contributions were pushed directly to this repository, while some files were uploaded here from Microsoft Teams (Elise worked via Teams for technical reasons). Everyone contributed and the team is proud of the end result.

## Project structure

- `index.php` — main entry point / contact page (includes a "Contact Us" form: name, email, phone, message).
- `style.css` — styling for the site.
- `items/` — item-related content (e.g. menu or product data/assets).
- `websites/` — additional website pages/sections.

## Requirements

- A PHP-capable web server (e.g. [XAMPP](https://www.apachefriends.org/), [MAMP](https://www.mamp.info/), or any server with PHP support).

## Running locally

1. Clone the repository:
   ```bash
   git clone https://github.com/hetgameboekje/Horeca.git
   ```
2. Place the project folder in your local server's document root (e.g. `htdocs` for XAMPP).
3. Start your PHP server and open `index.php` in the browser.
